# ReliefCare Mobile

## Tài liệu ưu tiên đọc

- `PROJECT_RULES_VI.md` — quy tắc dự án, bao gồm rule bắt buộc dùng tiếng Việt
- `mobile-api-guide.md` — tài liệu API mobile
- `goong-maps-reactnative.md` — ghi chú map/native map

## Khởi động dự án

### Cài thư viện

```bash
npm install
```

### Chạy Metro

```bash
npx expo start
```

### Chạy Android Dev Client

```bash
npx expo run:android
```
